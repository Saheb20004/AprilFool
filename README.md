# 🎭 April Fool's Day Website

A fun and interactive April Fool's Day website built with **React**, **Vite**, and **Tailwind CSS**, themed in lightseagreen (`#20b2aa`).

## ✨ Features

- **Floating Hero** — Animated 🎭 header with a festive greeting
- **Countdown Timer** — Counts down to reveal a fake "big secret" with a surprise image
- **Joke Cards** — 3 clickable prank cards that wiggle when tapped
- **Escape Button** — A sneaky button that dodges your cursor every time you try to click it
- **Custom Animations** — `wiggle`, `float`, and `blink` CSS keyframe animations

## 🛠️ Tech Stack

- [React 19](https://react.dev/)
- [Vite 8](https://vitejs.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
